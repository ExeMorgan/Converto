# Converto
Converto est une plateforme gratuite tout-en-un pour gérer vos fichiers. Convertissez vos documents, compressez-les, extrayez du texte depuis vos images avec l’OCR et modifiez vos PDF facilement grâce al'éditeur de tex. Une solution rapide, simple et accessible à tous pour répondre à besoins numériques, sans installation.!
